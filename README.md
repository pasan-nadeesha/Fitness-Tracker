# 🏋️‍♂️ AURAFIT - Interactive Fitness & Health Tracking Web Application

A modern, responsive, and user-centric Frontend Web Application designed to help individuals monitor their daily fitness health journey, track workouts, and check BMI. Built for the **ICT 1209 - Web Technologies** mini-project.

---

## 📌 Project Theme & Overview

**AURAFIT** is a personal fitness tracking platform that offers a comprehensive user dashboard, interactive wellness modules, and authentication interfaces to help users harmonize workouts, and daily lifestyle habits.

* **GitHub Repository:** https://github.com/pasan-nadeesha/Fitness-Tracker
* **Submission Phase:** Phase 2 – Frontend Layout & Design

---

## 🛠️ Requirements & Implemented Features

### 🎨 Frontend Layout & Structure

* **Multi-Page Layout:** Fully structured HTML pages:
  * `index.html` - Home page with hero banner, feature categories, and registration/login access.
  * `dashboard.html` - Interactive fitness health dashboard with user metrics and visual analytics.
  * `about.html` - Vision, mission, and project context.
* **Responsive Design:** Fluid grid layout optimized for Mobile, Tablet, and Desktop screens using **Bootstrap 5**.
* **Consistent UI Elements:** Clean navigation bar and footer present on all pages.
* **Bootstrap 5 Components:** Navbar, Cards, Carousel, Modals, and Styled Buttons.

### ⚡ JavaScript Features

1. **Dynamic Content Updates:** Filtering categories and live dynamic metrics updating on the dashboard without page reloads.
2. **Interactive Image Slider:** Auto/Manual carousel browsing for hero banners and featured content.
3. **Form Validation:** Real-time email validation, password checks, and required field feedback on user authentication forms.

---

## 🚀 Technologies Used

* **HTML5:** Semantic site structure and layout.
* **CSS3:** Custom styling and consistent visual themes.
* **Bootstrap 5:** Vector icon library for UI elements.
* **JavaScript:** Client-side logic for BMI calculation, dynamic tab switching, DOM manipulation, and form validation.
